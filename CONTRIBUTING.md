# Contributing to GameBEX

## Setup

```sh
export JAVA_HOME=~/jdk17 ANDROID_HOME=~/android-sdk
./gradlew :app:testDebugUnitTest :source-runtime:test :app:assembleDebug :app:lintDebug
```

JDK 17 and the Android SDK paths above are the project standard.
CI runs the same gates plus the extraction check on every push/PR.

## Rules that matter here

- **D-pad first.** Every screen must be fully drivable with
  Up/Down/Left/Right + A/B/X/Y. Touch may exist, but a controller
  alone must suffice. Test focus order on-device.
- **Honest states, never stubs.** Prep, download, and launch code
  must report what is actually true: a format the core can't boot
  is `NEEDS_MANUAL` with the fix named, not `READY`. Fail open
  (previous behavior) only when detection itself is uncertain.
- **No catalog in the app.** ROM-site support lives in
  user-imported JSON under `:source-runtime` policy only. Do not add
  site clients, hardcoded hosts, or per-site branches to `app/`.
  The extraction check (`git grep` in CI) enforces this.
- **No copied emulator code.** Touch controls and other behavior
  that matches an emulator are written from its docs, its resource
  files and on-device measurement. Don't paste or translate an
  emulator's source, and never use code from a decompiled app.
- **No ROMs/BIOS in the repo.** Test fixtures must be synthetic
  (generated bytes, not dumps). Never commit firmware, keys, or
  credentials; user credentials live in app-private prefs only.
- **Tests stay green.** Pure logic gets JVM unit tests next to the
  change (`PrepLogic`/`PrepPipeline` pattern: pure helpers +
  bounded file IO). Behavior changes need a regression test and,
  when the branch is device-only, a note saying so.
- **Don't nuke user data.** Never `pm clear`, uninstall, or wipe
  the library to make a test pass; installs are `adb install -r`.

## Workflow

1. Fork, branch, change, run the gates above.
2. Keep diffs reviewable: one behavior per PR, tests included.
3. PRs update docs when behavior changes (README matrix, schema,
   or prep notes as applicable).

## License and sign-off

GameBEX is under AGPL-3.0-or-later, and contributions come in under
the same license. Sign off each commit (`git commit -s`) to certify
the [Developer Certificate of Origin](https://developercertificate.org/):
you wrote the change, or otherwise have the right to submit it under
this license.

Questions? Open an issue — device details (model, Android version,
core/emulator versions) help enormously.
