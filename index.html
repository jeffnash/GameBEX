Plugins

Browse the site's catalog in GameBEX.

Pick a compatible ROM site, copy the prompt, and let your coding agent build its JSON plugin. Import it and the catalog appears in Discover. Reuse the same prompt for other sites; each gets its own plugin. The site needs public pages the plugin can read; support depends on how the site works.

Browse the catalog without downloading every game. Download a game when you want to play it, and remove its local files from the game page when you need the space.

How plugins work
Play together

Play together on two phones.

Stream sends the host's game picture and sound to a second phone, and brings player two's controls back. Only the host needs the game and emulator; the joining phone just needs GameBEX. Play supported local two-player games across systems, even without native netplay. Both phones stay on the same Wi-Fi.

Press 2P to invite a friend. Where a native mode is available, choose Use Stream instead. The Stream host needs Android 13+ and Shizuku; the joining phone needs Android 10+. RetroArch netplay, Game Boy link, and PSP ad hoc are available too.

Host phone
Your game, its emulator, and player one's controls. Android 13+ with Shizuku.
Joining phone
GameBEX and player two's controls. Android 10+; no game, emulator, or matching core needed.

System

Install emulators. See what each game needs.

GameBEX picks an emulator for each of its 54 playable systems. Open System to install it or follow its download link. RetroArch cores download when needed, and GameBEX suggests settings for your phone's CPU and RAM. With Shizuku running, it can also close other emulators before a launch to free up memory.

GameBEX sets up your controller in RetroArch, and Vita3K reads it natively. Flycast, Dolphin, and NetherSX2 need Shizuku, a free helper app, for GameBEX to change their settings. Dolphin and NetherSX2 also need a one-time mapping step in their own menus.

If a game needs a BIOS file or disc preparation, its page shows Finish Setup and lists what's missing. Press it to run the setup steps GameBEX supports.

Game performance depends on your phone and the emulator.

Install

Install GameBEX 1.0.0

GameBEX isn't on the Play Store, so you sideload the APK, which takes a few minutes.

Your phone needs

  • Android 8.0 or newer (Android 11+ recommended)
  • A 64-bit ARM phone
  • Landscape only (there's no portrait layout)
  • A controller, though touch works
  • Shizuku for the full controller setup (optional)
