Notes

Section titled “Notes”
  • PlayStation 2 games boot directly in NetherSX2. ARMSX2 is an alternative, which you can pick per game under Advanced → Emulator → Change on the game’s page.
  • PS Vita games are installed inside Vita3K itself.
  • Arcade sets (MAME, Neo Geo, NAOMI) stay zipped with their exact short names, for example galaga.zip.
  • Supported file types and disc preparation are covered in Formats & disc prep.
